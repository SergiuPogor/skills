# Run persistent multi-agent terminal workspaces with TUIOS

Use TUIOS to keep coding agents in persistent tiled terminal sessions, monitor their state, route Inbox items, and coordinate work across local or remote panes.

## Prerequisites

TUIOS CLI, supported terminal, one or more CLI coding agents such as Claude Code, Codex, Gemini CLI, or opencode; optional SSH, Tailscale, and MCP-compatible client

## Installation

Install or set up from the source-backed instructions:

Install with Homebrew using brew install tuios, Nix using nix run github:Gaurav-Gosain/tuios#tuios, Go using go install github.com/Gaurav-Gosain/tuios/cmd/tuios@latest, the upstream install script, or a GitHub release binary. Then run tuios integration install for supported agent harnesses and start or attach to a session before launching agent panes.
