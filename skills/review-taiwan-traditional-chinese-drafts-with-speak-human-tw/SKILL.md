# Review Taiwan Traditional Chinese drafts with speak-human-tw

Use speak-human-tw when an agent should identify AI-writing fingerprints in Taiwan Traditional Chinese drafts, suggest localized revisions, and preserve the writer's intent instead of generating generic copy.

## Prerequisites

Claude Code, Codex, Cursor, or another agent/runtime that can read a SKILL.md file; Taiwan Traditional Chinese draft text

## Installation

Install or set up from the source-backed instructions:

For Claude Code, clone the repository into ~/.claude/skills/speak-human-tw. For Codex one-shot usage, clone the repository, run codex exec -C . with instructions to read ./SKILL.md, and paste the draft text. Cursor and symlink install options are documented in the upstream README.
