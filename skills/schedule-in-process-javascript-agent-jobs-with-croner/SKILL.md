# Schedule in-process JavaScript agent jobs with Croner

Use Croner when a JavaScript, TypeScript, Deno, Bun, or browser-based agent service needs zero-dependency cron parsing, next-run previews, timezone-aware schedules, overrun protection, and in-process recurring jobs.

## Prerequisites

Node.js 18 or newer, Deno 2 or newer, Bun 1 or newer, or a browser JavaScript runtime; Croner package; custom agent service code

## Installation

Install or set up from the source-backed instructions:

Install with npm install croner, bun add croner, import from jsr:@hexagon/croner in Deno, or use the documented browser bundle. Then import Cron from croner, define cron patterns and scheduled functions, and verify nextRun or nextRuns before enabling recurring agent work.
