# Find repository context for coding agents with Jevgrep

Ask a natural-language codebase question and return ranked files, source excerpts, and reading leads so a coding agent can start work with grounded context.

## Prerequisites

Node.js 22+, npm, jg CLI, supported Jevgrep provider credentials

## Installation

Install or set up from the source-backed instructions:

Install with `npm install --global @dzhng/jevgrep@latest`, run `jg auth` to choose and save a supported provider credential, then run `jg skill` or `npx skills add dzhng/jevgrep --skill jevgrep` from the project where the coding agent works.
